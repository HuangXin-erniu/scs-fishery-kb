# Glossary

Bilingual terminology used across the project. Statistical and legal definitions
vary by source; confirm the exact wording against the cited document or a domain
expert before treating a definition as authoritative.

| English | 中文 | Notes |
|---|---|---|
| nearshore | 近海 | Scope term; the exact boundary follows the cited source. |
| fishing vessel | 渔船 | Vessel used for capture operations. |
| fishing operation | 捕捞作业 | Operation type and duration are source-specific. |
| catch | 渔获量 | Often distinguished from landed weight; confirm the definition per source. |
| landed weight | 上岸量（卸港量） | Weight landed at port; may differ from catch. |
| fishing effort | 捕捞努力量 | Units vary (days, trips, kW-days); confirm the unit per source. |
| fishing ground | 渔场 | Area associated with a fishery or season. |
| fishing season | 渔汛 | Seasonal window of a fishery; source-specific. |
| seasonal closure | 伏季休渔 | Closure period defined by regulation; cite the effective version. |
| logbook | 捕捞日志（渔捞日志） | Record kept by a vessel or operator. |
| voyage | 航次 | Trip from departure to return; confirm the boundary definition. |
| operating day | 作业日 | A day with fishing operations; confirm the counting rule. |
| port stay | 停港 | Time in port; may include transhipment or landing. |
| gear | 渔具 | Fishing gear type; use the standard classification where available. |
| mesh size | 网目尺寸 | Gear parameter; cite the applicable standard. |
| AIS | 船舶自动识别系统 | Automatic identification system; only dictionaries and desensitised samples are in scope. |
| VMS | 船位监控系统 | Vessel monitoring system; full tracks are out of scope. |
| SST | 海表温度 | Sea surface temperature; record product, unit and resolution. |
| chlorophyll-a | 叶绿素 a | Ocean-colour indicator; record product and unit. |
| anomaly | 距平 | Difference from a reference period; state the reference. |
| indicator | 指标 | Measurable quantity used in analysis or retrieval. |
| statistical definition | 统计口径 | Definition and counting rule used by a statistical source. |
| metadata | 元数据 | Descriptive and provenance fields for a source or product. |
| corpus | 语料库 | Governed collection of sources used by the knowledge base. |
| chunk | 知识片段（切块） | Retrieval unit derived from a document with page/section anchors. |
| citation | 引用 | Pointer to evidence, formatted as `[doc_id p.page]`. |
| abstention | 拒答 | Explicit refusal when evidence is insufficient. |
| retrieval-augmented generation (RAG) | 检索增强生成 | Answer generation grounded in retrieved evidence. |
| source register | 来源登记 | Register of sources, licences, sensitivity, versions and hashes. |
| sensitivity | 敏感级 | Public, internal, restricted or unknown; controls handling. |
| licence | 许可 | Terms under which a source may be used or shared. |
