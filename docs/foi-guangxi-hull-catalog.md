# 广西海洋捕捞渔船标准船型目录：政府信息公开申请

> **摘要**：广西是目前唯一没有公开海洋捕捞渔船标准船型目录的沿海省区。公开页面均无法取得该目录，因此本文件提供一份可直接提交的政府信息公开申请书，明确申请范围、法律依据、提交渠道、所需材料与二十个工作日时限，并约定回执与答复的跟踪方式。提交由所有者以本人身份完成，项目只记录结果。

## 1. 为什么要走依申请公开

- 自治区农业农村厅的通知公告与文件资料列表返回 200，但内容由脚本加载，页面内没有船型条目；
- 原自治区海洋和渔业厅域名 `gxao.org.cn` 已返回 404；
- 引用该目录的钦州市批复页面也已返回 404；
- 搜索只能找到内陆渔业趸船标准（桂农厅办发〔2020〕47号，属内河、不在本项目范围）和引用目录但不附目录的地市批复。

按项目规则，新闻与地市批复只能作为线索，不能替代省级目录。依申请公开是取得省级原文、文号、日期与有效性的唯一可靠路径。
