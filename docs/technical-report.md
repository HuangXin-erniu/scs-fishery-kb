# 技术报告

> **中文摘要**：本报告给出 SCS-FKB 的技术路线、当前可复现指标和未完成项。聚合指标、
> 确定性审计和人工盲审分开陈述；512 产品路径产物因串号已撤回，最新 150 题人工盲审为
> **81/150（54.0%）**，低于验收线。报告不宣称验收通过，也不把模型判定写成人工结论。

## 1. 目标与范围

本课题建设南海近海渔业知识库（SCS-FKB）：把分散在法规、标准、统计年鉴、公报、论文与
业务规范中的知识组织成可追溯的语料，提供带引用的检索增强问答，并在证据不足时明确拒答。

范围内：渔业船舶作业与渔情知识、统计口径、法规与标准、公开论文与报告；接口契约与本地服务。
范围外：预报模型训练、原始环境栅格、完整 AIS/VMS 轨迹、生产级多租户部署、下游平台数据集成。

## 2. 方法与技术路线

### 2.1 受治理语料

- 每个来源登记许可、敏感度、权威等级、时效、版本与哈希（`configs/corpus.yaml`）。
- 处理流程：快照 → 解析（PyMuPDF/Docling 可选）→ 结构感知切分（章节/条款/表格锚点）→ 入索引。
- 当前：**139 个来源（137 canonical / 2 provisional）**、**107 份文档 / 3,940 块**，
  索引版本 `251dbf67e804`；索引目录 + `current.json` 原子指针 + 回退路径。
- 2021 年《国家重点保护野生动物名录》已登记为 `STD-SPEC-076`，未重复补录；其 OCR 分块
  存在表格错位，引用时按页/章节锚定，不把 OCR 噪声当作原文结论。

### 2.2 混合检索

- 词法：字符二元组 BM25；向量：`BAAI/bge-small-zh-v1.5`（512 维、归一化，本地 ONNX）；
  融合：RRF；元数据过滤：jurisdiction、时效、敏感度。
- 重排：`BAAI/bge-reranker-v2-m3-int8` 可选；公开集 A/B 显示 recall@5 0.8298→0.8085、
  P95 22ms→1947ms，默认关闭；产品路径只在诊断时开启。
- 公开回归集 47 条可检索题：可达 44 条上 recall@5 **0.8864**、MRR **0.7848**；全量口径
  **0.8298 / 0.7348**。

### 2.3 引用与拒答

- 答案逐句带 `[DOC §章节]` 引用，引用必须解析到检索命中的块；数字必须逐字出现在被引证据中。
- 三层拒答：澄清（问题过泛/含未知年份）、检索门控（证据不足）、充分性判定
  （`SCS_FKB_VERIFY_ANSWERS=on` 时由模型判定证据是否足以回答）。
- 答前增加一次“证据复核”：证据中存在可直接回答的条款时，强制给出带引用答案；无引用或
  引用不成立则丢弃。该复核不能替代人工判断。
- 512 题冻结仪器的 **dump 聚合臂**（index `251dbf67e804`）：覆盖 **0.8129**、引用
  **0.9544**、时效 **0.9123**、误答 **0.0000**、拒答渠道 **1.0000**、口径 **0.9412**。
  这些是聚合指标，不是用户可见答案的逐条审计。

### 2.4 答案一致性与串号门禁

- `scripts/check_answer_consistency.py` 对整批答案做两项检查：
  - `DUP_ANSWER`：不同 id 出现相同/高度相同的答复正文；非空即整批作废；
  - `TOPIC_MISMATCH`：问句主题未出现在答复/引用中，作为修稿提示。
- 该门禁是 2026-11-17 事故后的硬门禁：512 产品路径产物曾因 Y-090/Y-499、
  Y-365/Y-510 等串号被污染，已整体撤回；per-id 通过率不得从该产物计算。

### 2.5 短答臂

- 可选形态：≤300 字，结论 → 依据 → 期限/材料 → 提醒，逐行带引用；校验失败回退确定性长答。
- 公开集 60 条：**16/60** 生成有效短答；开启充分性校验时无证据题全部弃答。
- 短答是可选臂，不是验收默认路径。

### 2.6 受控网络证据

- 默认关闭；开启时只做线索（`web_leads`），永不进入答案、引用或弃答判定；来源白名单与 TTL。
- 候选进入 `configs/candidates.yaml` 后仍需人工许可/权威性审查、下载、哈希和登记，才可能进入索引；
  当前候选仍为 open，未自动入库。

## 3. 系统实现

| 层 | 组件 | 说明 |
|---|---|---|
| 语料 | `ingest_v2/`, `parsers/` | 解析、切分、锚点、隔离与 OCR 可选 |
| 索引 | `index_v2/` | LanceDB + LlamaIndex 向量存储，版本目录与原子指针 |
| 检索 | `retrieve_v2/` | BM25 + BGE + RRF，过滤、改写、可选重排 |
| 回答 | `answer_v3/` | 契约组装、引用校验、拒答、短答、事实引导 |
| 服务 | `service_v2/` | `/v1` 合同、`/kb` 工作台、反馈、指标 |
| 知识层 | `facts.py`, `terms.py`, `kb_v2/` | 事实/术语/playbook 校验与分层存储 |
| 审计 | `audit/` | D1–D11 检测器、台账、一致性门禁 |

- `/v1` 合同见 [interface.md](interface.md)；`/kb` 面向船员、船东、执法与推广四类用户。
- 依赖：`pyproject.toml` 的 core + `rag`/`service`/`dev` extras；模型客户端为 `openai` SDK。
- 可复现：索引 manifest 记录 `code_commit` 与 `pipeline_config_sha256`。

## 5. 人工盲审结论

2026-11-17 的 150 题人工盲审结果为 **81/150 通过（54.0%）**，Wilson 95% 下界 46.0%，
低于“≥90% 且下界 ≥85%”的验收规则；在这个样本量下需要至少 137 题通过。缺陷分布：

| 类 | 数量 | 说明 |
|---|---:|---|
| C1 该答未答 | 21 | 语料有定义/条文却拒答 |
| C2 子问遗漏/结论缺失 | 20 | 只列条款，漏数值或结论 |
| C3 答非所问/原文倾倒 | 19 | 检索错配、案例倾倒、OCR 噪声 |
| C4 事实/依据错误 | 4 | 旧罚则、机关错配、物种级别 |
| C6 模板/口径污染 | 4 | 通用执法段落注入休渔题 |
| C5 引用错挂 | 1 | 引用锚点与句子不匹配 |

引用层相对稳定：118 条有锚点的答复中 115 条引用真实且支撑；主要问题不是引错，而是答不到。
69 条失败已全部锁进回归集；修复后的回归重跑 0 串号、0 确定性缺陷，但尚未做新一轮人工判定。

## 6. 已知限制

- **验收样本池耗尽**：512 池中未进过任何人工复核/盲测的题只剩 62 道；两轮 150 题盲测
  （`blind-150-next`、`blind-150-v2`）均因 `DUP_ANSWER` 被撤回为回归集，无法再抽合格 150。
  在拿到新的 ≥150 未用题池前，验收不能继续，也不降样本量或门禁。
- **串号风险**：宽泛兜底分支曾让不同问题共用同一答案；现已按问句意图拆分，并加硬门禁，
  但仍需在全新题池上验证，不能以回归集自证。
- **覆盖天花板**：冻结仪器下覆盖受术语锚定与语料边界限制，0.8129 为已发布线；
  不在本报告里把聚合指标外推为用户可见答案质量。
- **短答有效率 16/60**：短答是可选能力，默认仍是长答。
- **单机单用户**：无鉴权、无监控、无高可用；定位是本地知识服务原型。
- **外部库不参与弃答**：事实/术语/卡片库在语料答案之后才被咨询，永不决定是否拒答。
- **人工层未完成**：30 行双标 kappa 仍为 `null`（缺第二名复核人）；30 题独立专家签字仍为空，
  项目侧不代签。
- **无第三方测评与发表物**：本课题交付技术报告、指标报告与可运行系统。

## 7. 数据与许可

- 公开仓库只含代码、配置与文档；数据、索引与运行产物留在仓库外的本地数据根。
- 来源许可、敏感度与可公开性逐条登记在 `configs/corpus.yaml`，未登记来源不进入语料。
- 不发布原始环境栅格、完整船位轨迹或可识别船舶信息。
- 不创建 tag/GitHub Release；`main` 即最新。

## 8. 复现

```bash
# 依赖
pip install -e ".[rag,service]"

# 检索与公开集
PYTHONPATH=src python scripts/eval_index_v2.py
PYTHONPATH=src python scripts/eval_public.py

# 512 聚合验收（冻结仪器；需要本地数据根）
SCS_FKB_VERIFY_ANSWERS=on SCS_FKB_WEB=off LLM_TIMEOUT=240 \
  PYTHONPATH=src python scripts/eval_accept.py --llm --llm-arm dump \
  --llm-answerability 可答,部分可答 --llm-workers 2

# 答案一致性（任何批次进入统计前）
PYTHONPATH=src python scripts/check_answer_consistency.py \
  --answers answers.jsonl --out consistency.json

# 短答公开集
SCS_FKB_VERIFY_ANSWERS=on SCS_FKB_WEB=off PYTHONPATH=src \
  python scripts/eval_short_public.py
```

## 9. 结论

技术侧已完成语料治理、混合检索、引用/拒答、超时硬化、缺陷修复、512 聚合指标、150 题确定性
审计和 69 条失败回归锁；但用户可见答案的人工盲审只有 **54.0%**，512 产品路径产物因串号
撤回，且当前题池无法再抽合格 150 题。**因此本报告不宣称验收通过，门禁保持关闭。**
下一步是取得新的 ≥150 未用题池，重跑一次盲测，再完成 30 行 kappa 与独立专家签字；
未完成前不写“通过”，也不降低已发布线。
