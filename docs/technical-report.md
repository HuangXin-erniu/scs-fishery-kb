# 技术报告（骨架）

> **中文摘要**：本报告是课题验收的技术报告骨架。已完成的部分直接给出内容与数字；标 `【待扩写】`
> 的章节是尚未展开的叙述性内容，不影响已给出的指标与复现路径。所有数字为聚合值，不含私有题面。

## 1. 目标与范围

本课题建设南海近海渔业知识库（SCS-FKB）：把分散在法规、标准、统计年鉴、公报、论文与业务规范中的
知识组织成可追溯的语料，提供带引用的检索增强问答，并在证据不足时明确拒答。

范围内：渔业船舶作业与渔情知识、统计口径、法规与标准、公开论文与报告；接口契约与本地服务。
范围外：预报模型训练、原始环境栅格、完整 AIS/VMS 轨迹、生产级多租户部署、下游平台数据集成。

## 2. 方法与技术路线

### 2.1 受治理语料

- 每个来源登记许可、敏感度、权威等级、时效、版本与哈希（`configs/corpus.yaml`，77 个来源）。
- 处理流程：快照 → 解析（PyMuPDF/Docling 可选）→ 结构感知切分（章节/条款/表格锚点）→ 入索引。
- 当前语料：67 份文档、2,797 块，索引版本 `ce3eeaf4c9b2`；索引版本目录 + `current.json` 原子指针
  + 回退路径。

### 2.2 混合检索

- 词法：字符二元组 BM25；向量：`BAAI/bge-small-zh-v1.5`（512 维、归一化，本地 ONNX）；
  融合：RRF；元数据过滤：jurisdiction、时效、敏感度。
- 重排：`BAAI/bge-reranker-v2-m3-int8` 可选；公开集 A/B 显示 recall@5 0.8298→0.8085、
  P95 22ms→1947ms，默认关闭。
- 公开回归集 47 条可检索题：可达 44 条上 recall@5 **0.8864**、MRR **0.7848**；全量口径
  0.8298 / 0.7348。

### 2.3 引用与拒答

- 答案必须逐句带 `[DOC §章节]` 引用，引用必须解析到检索命中的块；数字必须逐字出现在被引证据中。
- 三层拒答：澄清（问题过泛/含未知年份）、检索门控（证据不足）、充分性判定
  （`SCS_FKB_VERIFY_ANSWERS=on` 时由模型判定证据是否足以回答）。
- 512 题仪器结果：误答 **0.0000**、拒答渠道 **1.0000**、引用 **0.9565**、时效 **0.9474**、
  覆盖 **0.8092**、口径 **0.9412**。

### 2.4 短答臂

- 可选形态：≤300 字，结论 → 依据 → 期限/材料 → 提醒，逐行带引用；校验失败回退确定性长答。
- 公开集 60 条：**16/60** 生成有效短答；开启充分性校验时 13 条无证据题全部弃答。
- 【待扩写】短答的适用边界与失败类型分布（当前失败集中在整行缺引用）。

### 2.5 受控网络证据

- 默认关闭；开启时只做线索（`web_leads`），永不进入答案、引用或弃答判定；来源白名单与 TTL。
- 【待扩写】周度只读巡检与人工准入流程的运行记录。

## 3. 系统实现

| 层 | 组件 | 说明 |
|---|---|---|
| 语料 | `ingest_v2/`, `parsers/` | 解析、切分、锚点、隔离与 OCR 可选 |
| 索引 | `index_v2/` | LanceDB + LlamaIndex 向量存储，版本目录与原子指针 |
| 检索 | `retrieve_v2/` | BM25 + BGE + RRF，过滤、改写、可选重排 |
| 回答 | `answer_v3/` | 契约组装、引用校验、拒答、短答、事实引导 |
| 服务 | `service_v2/` | `/v1` 合同、`/kb` 工作台、反馈、指标 |
| 知识层 | `facts.py`, `terms.py`, `kb_v2/` | 事实/术语/playbook 校验与分层存储 |

- `/v1` 合同见 [interface.md](interface.md)；`/kb` 面向船员、船东、执法与推广四类用户。
- 依赖：`pyproject.toml` 的 core + `rag`/`service`/`dev` extras；模型客户端为 `openai` SDK。
- 可复现：索引 manifest 记录 `code_commit` 与 `pipeline_config_sha256`。

## 5. 已知限制

- **覆盖天花板**：132 个未覆盖点中 79 个的术语在整个语料中不存在；术语存在的 38 个里只有 3 个能
  在同一章节内同时出现，章节扩展最多回收 3 个点。覆盖 0.815 在冻结仪器下不可达。
- **短答有效率为 16/60**：短答是可选能力，默认仍是 dump 长答；两次提示词改进都因端点吞吐无法测量。
- **单机单用户**：无鉴权、无监控、无高可用；定位是本地知识服务原型。
- **外部库不参与弃答**：事实/术语/卡片库在语料答案之后才被咨询，永不决定是否拒答。
- **无第三方测评与发表物**：本课题交付技术报告、指标报告与可运行系统。
- **人工复核尚未完成**：30 题样本已冻结；2026-11-11 做了一次 AI 多角色模拟抽检
  （P24-ACC-227，引用 16/20、结论 5/20、拒答 7/10），只作预演，独立人工签字仍待完成。
  主因是 dump 臂的摘要/结论抽取错位：15 道结论未过中 14 道的正确条款在全文里但没进摘要。

## 6. 数据与许可

- 公开仓库只含代码、配置与文档；数据、索引与运行产物留在仓库外的本地数据根。
- 来源许可、敏感度与可公开性逐条登记在 `configs/corpus.yaml`，未登记来源不进入语料。
- 不发布原始环境栅格、完整船位轨迹或可识别船舶信息。

## 7. 复现

```bash
# 依赖
pip install -e ".[rag,service]"

# 检索与公开集
PYTHONPATH=src python scripts/eval_index_v2.py
PYTHONPATH=src python scripts/eval_public.py

# 512 验收（冻结仪器；需要本地数据根）
SCS_FKB_VERIFY_ANSWERS=on SCS_FKB_WEB=off LLM_TIMEOUT=240 \
  PYTHONPATH=src python scripts/eval_accept.py --llm --llm-arm dump \
  --llm-answerability 可答,部分可答 --llm-workers 2

# 短答公开集
SCS_FKB_VERIFY_ANSWERS=on SCS_FKB_WEB=off PYTHONPATH=src \
  python scripts/eval_short_public.py
```
