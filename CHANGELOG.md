# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-alpha] - 2026-10-30

### Added

- Public project scope, objectives, non-goals and roadmap.
- Governed source register with licences, sensitivity and acquisition notes.
- 24 draft evaluation questions covering vessel operators and fisheries administration.
- Data policy, method outline and documentation index.
- Public-tree validation script, configuration tests and CI workflow.
- Apache-2.0 code licence, CC BY 4.0 documentation licence and citation metadata.
- Contributing, code of conduct, security and issue/PR templates.

### Notes

- This is a documentation and configuration baseline. No retrieval or service code is included yet.
- No data payloads, indexes, run artifacts or state databases are published.
- The downstream interface contract is planned for a later milestone and is not implemented here.
